# Método Navas — Central de Links

### Todos os caminhos do Método Navas em um só lugar.

Esta é a **central oficial de links do Método Navas**: a página que fica na bio das redes sociais e conecta quem chega até o projeto a tudo o que ele oferece, como o treinamento completo, os conteúdos gratuitos e o contato direto com o time.

---

## 💡 O propósito

O Método Navas ensina pessoas comuns, sem nenhuma experiência em programação, a criar sites com Inteligência Artificial e transformar essa habilidade em uma fonte de renda.

Quem descobre o método pelo TikTok ou pelo Instagram precisa de um próximo passo claro. Esta página existe para isso: ser a **porta de entrada** do projeto, com uma apresentação direta e caminhos simples para conhecer mais.

## 🎯 O intuito da página

Em poucos segundos, o visitante entende quem é o Método Navas e para onde ir:

- **Conhecer o treinamento**: o link de destaque leva direto ao curso completo
- **Aprender de graça**: vídeos rápidos no TikTok e dicas no Instagram
- **Tirar dúvidas**: contato direto pelo WhatsApp com o time do Navas

Tudo leva a uma única chamada final: **"Quero conhecer o método"**.

## 🎨 A experiência

A página segue a mesma identidade visual do Método Navas, pensada para transmitir **tecnologia, confiança e modernidade**:

- Tema escuro com brilhos em azul neon, a cor da marca
- Cards com efeito de vidro e um reflexo de luz que percorre cada link
- O link do treinamento em destaque, para guiar o olhar
- Entrada suave e em cascata dos elementos ao abrir a página
- Feita primeiro para o celular, onde está quase todo o público que vem das redes
